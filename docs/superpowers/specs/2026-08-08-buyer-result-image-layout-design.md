# 買房方向卡下載圖片排版優化設計

日期：2026-08-08
適用網站：https://buyer.tainanwei.com/

## 目標

優化網站「儲存需求照片」產生的 1080 × 1350 PNG，使版面更舒適、易讀且更像可直接分享的品牌方向卡。新版移除右上角電話，重新整理標題、段落行距、區塊留白與底部聯絡區；電話只在底部出現一次。

## 核准的視覺方向

- 延續既有暖白、墨綠與金色的精緻顧問風格，不更換品牌配色或卡片尺寸。
- 頂部左側保留「台南小魏／買厝作伙」品牌識別；右上角電話完全移除，改為有意識的留白。
- 狀態標籤維持膠囊造型，作為品牌區與主標題間的視覺節點。
- 主標題仍固定為兩行，但略微縮小字級並增加行距，避免筆畫密集與行距壓迫。
- 「目前找房方向」「預算提醒」「最值得先確認的 3 件事」維持原順序與內容來源，重新分配區塊間距，使內容不擁擠，也不在第三區與頁尾間留下過大的空洞。
- 段落與清單提高行距，統一縮排；金色方形項目符號與 01／02／03 編號繼續作為掃讀錨點。

## 頁尾設計

頁尾維持深墨綠圓角底，改成三行置中排列：

1. `想了解台南行情、買房、賣房，都可以找我聊聊。`
2. `魏泉承｜永慶不動產－小東南紡店`
3. `0927-617-207`

第一行使用暖白色，第二、三行使用金色系；電話僅在此處出現一次。三行需有清楚的字級層次與均勻垂直間距，整組以頁尾中央軸線對齊，不再採左右分欄。

## 實作邊界

- 只修改 Canvas 圖片產生器與其測試，不改網站結果頁內容、問卷、送單 payload、Apps Script、Google Sheet、LINE 或電話連結。
- PNG 尺寸維持 1080 × 1350，檔名與下載流程維持不變。
- 圖片仍只使用經 allowlist 清理後的答案產生公開方向內容。
- 不得將買方姓名、手機號碼、LINE ID、其他自由輸入或非法選項值畫入圖片。
- 品牌電話固定為 `0927-617-207`，只能在頁尾置中區出現一次。
- 長文字仍需受最大行數與安全邊界限制，所有內容與頁尾不得裁切或重疊。

## 測試與驗收

- 以 Node Canvas 假實作驗證：右上品牌區不再繪製電話；品牌電話只繪製一次；頁尾三行皆置中；輸出維持 1080 × 1350；既有個資遮蔽與安全答案測試持續通過。
- 以 Playwright 驗證桌面與行動專案皆能下載 PNG，檔案簽章、尺寸、toast 與下載檔名正確。
- 以真實 Chromium 產生完整內容與長文字兩張 PNG，目視檢查字級、行距、留白、換行、頁尾置中與裁切。
- 執行完整 Node、Playwright、JavaScript syntax check 與 `git diff --check`。

## 不在本次範圍

- 不更換字型檔或加入外部字型 CDN。
- 不改為其他社群尺寸，也不新增多尺寸選擇。
- 不重新設計網站上的結果卡與聯絡表單。
- 不修改品牌名稱、公司名稱、CTA 或電話內容。
